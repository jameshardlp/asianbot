# Telegram Asian Bot 🌸

Бот для Telegram, который отправляет фото азиатских девушек каждые 3 часа.

## Возможности

- 🔍 Поиск фото в интернете (Bing, Google, Pexels)
- 🌏 Только азиатки: японки, китаянки, кореянки
- 📸 Отправка каждые 3 часа
- 👥 Работает во всех чатах, где является админом

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Активировать бота в чате |
| `/photo` | Получить фото сейчас |
| `/status` | Статус бота |
| `/stop` | Отключить бота |

## Установка

### Через Docker

```bash
docker build -t asian-bot .
docker run -d --name asian-bot --env-file .env --restart unless-stopped asian-bot
